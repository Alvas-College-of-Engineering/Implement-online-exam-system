# Online Exam System

## Project Description
This project is a Java-based Online Exam System developed to allow students to log in, attend multiple-choice exams, and view results automatically.

## Features
- User login authentication
- Multiple-choice question system
- Automatic score calculation
- Result display
- Simple web-based interface using Java

## Technologies Used
- Java
- HTML
- HTTP Server
- VS Code
- GitHub

## Project Structure
- model → contains data classes
- repository → stores question and user data
- service → business logic
- web → server and web handling

## How to Run
1. Open project in VS Code
2. Compile Java files
3. Run Main.java
4. Open browser and access local server
